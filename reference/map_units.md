# world map_unit polygons from Natural Earth

map_unit polygons at scales 1:110m (small), 1:50m (medium). 1:10m
(large) are in the package rnaturalearthhires. There are more map_units
than countries e.g. United Kingdom is split into England, Scotland,
Wales and Northern Ireland.

## Usage

``` r
map_units110

map_units50
```

## Format

An object of class \`sf\`

An object of class `sf` (inherits from `data.frame`) with 183 rows and
169 columns.

An object of class `sf` (inherits from `data.frame`) with 265 rows and
169 columns.
