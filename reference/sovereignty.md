# world sovereignty polygons from Natural Earth

sovereignty polygons at scales 1:110m (small), 1:50m (medium). 1:10m
(large) are in the package rnaturalearthhires. There are fewer sovereign
states than countries e.g. the Falkland Islands are included with the
United Kingdom.

## Usage

``` r
sovereignty110

sovereignty50
```

## Format

An object of class \`sf\`

An object of class `sf` (inherits from `data.frame`) with 171 rows and
169 columns.

An object of class `sf` (inherits from `data.frame`) with 201 rows and
169 columns.
