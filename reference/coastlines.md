# world coastlines from Natural Earth

coastline lines at scales 1:110m (small), 1:50m (medium). 1:10m (large)
are in the package rnaturalearthhires.

## Usage

``` r
coastline110

coastline50
```

## Format

An object of class \`sf\`

An object of class `sf` (inherits from `data.frame`) with 134 rows and 4
columns.

An object of class `sf` (inherits from `data.frame`) with 1428 rows and
4 columns.
