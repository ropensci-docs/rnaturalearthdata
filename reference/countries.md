# world country polygons from Natural Earth

at scales 1:110m (small) and 1:50m (medium). 1:10m (large) are in the
package rnaturalearthhires.

## Usage

``` r
countries110

countries50
```

## Format

An object of class \`sf\`

An object of class `sf` (inherits from `data.frame`) with 177 rows and
169 columns.

An object of class `sf` (inherits from `data.frame`) with 242 rows and
169 columns.
