# tiny countries points from Natural Earth

small country points at scales 1:110m (small), 1:50m (medium).

## Usage

``` r
tiny_countries110

tiny_countries50
```

## Format

An object of class \`sf\`

An object of class `sf` (inherits from `data.frame`) with 37 rows and
171 columns.

An object of class `sf` (inherits from `data.frame`) with 76 rows and
171 columns.
