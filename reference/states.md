# state (admin level 1) polygons from Natural Earth

For Australia, Brazil, Canada and USA, at 1:50m (medium) resolution. The
package rnaturalearthhires has all world countries at 1:10m (high)
resolution.

## Usage

``` r
states50
```

## Format

An object of class \`sf\`

An object of class `sf` (inherits from `data.frame`) with 294 rows and
122 columns.

## Source

<https://www.naturalearthdata.com/http//www.naturalearthdata.com/download/50m/cultural/ne_50m_admin_1_states_provinces.zip>

## Slots

- `data`:

  A data frame with attributes
